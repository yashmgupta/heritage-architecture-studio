# Security policy

## Scope

The app is a static HTML application: it runs locally or on GitHub Pages, stores named studies in browser-local storage when allowed, and processes user-selected images in the browser. The current design does not require login or a server-side account.

## Report a vulnerability

**Do not publish exploitable security details in a public issue.** After you create the GitHub repository, enable GitHub's **Private vulnerability reporting** under repository security settings, if available, and use that channel for private reports. If that feature is not enabled, wait for an owner-designated private contact method before sharing sensitive details.

Please include a reproducible test case, browser/OS versions, expected vs. actual behavior, and whether local data or external content is affected. Please avoid testing against other people's data or services.

This policy does **not** promise a response or patch timeline; maintainers will handle reports as capacity permits.
